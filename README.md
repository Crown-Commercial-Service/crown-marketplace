# ⚠️ Reserved Branch (AWS CodePipeline Integration)

> **DO NOT MERGE CODE OR PUSH FUNCTIONAL COMMITS TO THIS BRANCH.**

---

### Purpose

This branch exists **solely** to support [AWS CodePipeline](https://aws.amazon.com/codepipeline/) triggers, pipeline routing, or source action stages. 

To maintain clean separation between infrastructure automation and active application development, this branch is kept intentionally empty of codebase assets.

---

### Instructions for Developers

* **Do NOT target this branch** for Pull Requests or feature merges.
* **Do NOT push feature code, hotfixes, or configuration files** directly to this branch.
* For all active development, please checkout `main` or the appropriate feature branch.
